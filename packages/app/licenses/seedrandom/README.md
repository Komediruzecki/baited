# seedrandom 3.0.5 notices

`NOTICES.txt` preserves the original comment headers from the installed `seedrandom.js` and non-minified `lib/*.js` files. It includes the complete MIT notices for David Bau's implementation and Johannes Baagøe's Alea implementation, plus the algorithm attribution headers for the other bundled generators.

The package has no standalone license file. Source filenames and input SHA-256 hashes are recorded in [`../packaging-notice-provenance.json`](../packaging-notice-provenance.json). The upstream project is [davidbau/seedrandom](https://github.com/davidbau/seedrandom), version 3.0.5. No implementation was changed.
