# BAIT 0.1.0

First private release checkpoint. This tag saves the game and landing source; it does not deploy either application.

## Landing

- All 18 approved pixel cards in one horizontal gallery, with left-to-right autoplay, mouse dragging, touch scrolling, keyboard navigation and explicit pause/play.
- Manual interaction stops autoplay. Hover, keyboard focus, reduced motion, hidden tabs and an offscreen gallery suspend nonessential motion.
- The mobile hero separates the bomb, word reveal, chat and catch stamp. Replay brings the example into view on small screens.
- The header no longer carries a design-study label. Custom hook and navigation SVGs replace decorative icon glyphs; the legacy app landing uses the same approved card art and a microphone illustration.
- Footer includes the approved Irchiinnuss identity, company/contact links and the game privacy notice.

## Game checkpoint

The existing game includes local Moonshine speech recognition with explicit catch confirmation, optional Deepgram, 18 illustrated words and opt-in Sound Lab effects. No speech API key is needed for the default local speech path.

## Verification and limits

Local browser review covers desktop, 390 × 844 and 320 px layouts, all five mobile example beats, replay, word selection, gallery controls and reduced motion. The generated illustrations remain byte-identical to the approved PNG originals.

Chromium at iPhone dimensions is not a physical Safari test. A real Twitch/OBS round with the owner's microphone and channel remains an acceptance step. No production deployment or public release is implied by this tag.

The deployable static landing is maintained separately in the private disjoint-colliders repository under `packages/bait`; its navigation is adapted for a static page and its privacy notice covers that page only.
