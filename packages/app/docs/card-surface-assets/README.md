# Card surface assets

Seven original materials were generated with an image model using the exact prompts in [the prompt catalogue](../card-surface-prompts.json), under [the written design direction](../card-surfaces-design.md). [manifest.json](manifest.json) records each full prompt, prompt hash, original PNG hash and dimensions, archive path, crop geometry, encoder arguments, quality, runtime hash and file budget. The tool did not return a model identifier.

Every runtime texture is below 160,000 bytes; each swatch is below 8,000 bytes. Optimization used ImageMagick only for technical crop, resize, metadata removal and WebP encoding. No creative rearrangement, mirroring, recoloring, text or logo was baked into these materials. Five 1024×1536 sources use the largest exact integer 5:7 crop (1020×1428); Spotlight and Seal arrived at 1060×1484 and needed no crop.

## Glass

Glass is an original code-only SVG material, not a generated raster or an image of glass. Its optics were specified from the [supplied reference](../glass-reference.md); see the [Glass design](../card-glass-design.md). Only the decorative light and ruled lines enter the displacement filter. The sprite and all typography remain outside it. The seven generated materials and their provenance above remain unchanged.

## Dither

`finishes/dither.svg` is generated by `scripts/build-card-dither.mjs`: a 72×101 crisp-edge grid with seed `0x00ba17ed`, three Bayer fade bands, sparse lilac edge cells and exact 180-degree symmetry. It contains only same-origin SVG paths and rectangles, with no text, scripts, linked resources or data URIs. Regenerate with `node scripts/build-card-dither.mjs`; verify with `node scripts/build-card-dither.mjs --check`.

## Limits and review

Generated backs are only approximately rotationally symmetric. The manifest records normalized mean absolute error against a 180-degree rotation for each optimized back; zero would mean exact symmetry. No artificial mirroring was applied. These are decorative base materials: the integration draws the original wordmark, opaque text plates, windows, frames and sprites above them. Actual 288 px card composites and browser fit, motion, contrast and readability need the integrated card renderer; standalone textures do not prove those checks.
