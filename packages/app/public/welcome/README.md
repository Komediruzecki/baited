# Welcome stage

`stage-1376.webp` and `stage-800.webp` are the stage plate behind thumbnail C of the V7 judging video ("the landing hero
over five cards"), which the owner chose for the pilot's welcome screen on 2 November 2026. The plate was generated with
Google's image model through Antigravity for that thumbnail set (agent-out run `43ca052b99254ff9be8298fdd26d0abc`,
`plate-stage-gemini.jpg`, SHA-256 `5db2ea00f46be26dba6d7c4e5a3ffd609cbcc27ecd50139fd5aa688aedd4d698`) and carries
Google's SynthID watermark. These copies are re-encoded WebP at 1376 and 800 pixels wide with metadata removed.

The cards in front of it are the Studio's own Cut Open cards, drawn live by `Landing.tsx`.
