# Demo video script

Target: **2 minutes 45 seconds**. Record a real Twitch channel after credentialed verification. Get permission for other people or third-party material in the recording.

| Time | Picture | Suggested narration |
| --- | --- | --- |
| 0:00–0:12 | Yellow banana headline and illustrated card/chat sequence. | “Chat wants you to say banana. Suddenly everyone has questions about smoothies. This is BAIT.” |
| 0:12–0:30 | Real Twitch stream, connected studio, consented mic and OBS. Start a round. | “Chat gets a secret word. Your studio and overlay keep it hidden. Keep streaming.” |
| 0:30–0:45 | Mobile viewer card, then a hint in real Twitch chat. | “Viewers join with a link. No account or extension. On Medium, the obvious clues are off limits.” |
| 0:45–1:10 | A real conversation leads the streamer to say the target. | Let the exchange play. Keep the response audible. |
| 1:10–1:25 | Synchronized reveal in the viewer room, studio and angular OBS frame. | “They said it. Chat wins together.” |
| 1:25–1:40 | Open You baited me and select a clean hint. Show the public award. | “Pick the hint that got you. A forbidden hint can’t get this award, but one chatter can’t lose the round for everyone.” |
| 1:40–1:56 | Three-word mission progress and private guess dialog. | “Want a longer game? Three words, one clock. Think you know the target? Type one private guess. Right: escape. Wrong: chat gets fifteen seconds.” |
| 1:56–2:10 | Reverse a deliberate false result, then pause/resume. | “Wrong detection? Reverse it. Pause freezes time and stops speech transmission.” |
| 2:10–2:32 | This Codex chat, source, session ID and actual test results. | “Codex helped build and test the game, Twitch connection and speech bridge. The source includes the verification record.” |
| 2:32–2:45 | Mobile card, real Twitch celebration and tested judge URL. | “One word. A very suspicious chat. BAIT.” |

Label any simulated footage. The landing illustration teaches the idea; the recorded victory must come from real Twitch chat and microphone recognition. Mark edits that shorten waiting time. Keep credentials, OAuth callbacks, overlay keys and unrelated conversations out of the video.
